FlyPoker V40 source overlay.
1. Backup local files/checkpoints.
2. Extract this archive into the Poker_fly repository root, keeping existing assets/checkpoints.
3. Run: py -m pip install -r requirements.txt
4. Run: py RUN_TESTS.py
5. Copy Unity/Assets/Script/*.cs to your separate Unity project Assets/Script/.
6. See README.md, COMMANDS.md and UNITY_SETUP.md.
